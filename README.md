# Arpit Anand Singh | Portfolio

A personal portfolio website showcasing my projects, skills, and contact information. It includes a project gallery, a skills section, a custom chatbot, and a few interactive mini-games.

## Live Demo

- Portfolio: https://portfolio-amananandsingh01.vercel.app/
- GitHub: https://github.com/amananandsingh01
- LinkedIn: https://www.linkedin.com/in/arpit-singh-26a943374

## Features

- Responsive personal portfolio landing page
- Project cards with screenshots and category filters
- Skills marquee and profile details
- Built-in chatbot for project and skill questions
- Mini games included in the site
- Clean, static frontend with no heavy build setup required

## Tech Stack

- HTML
- CSS
- JavaScript
- Vercel (deployment)

## Run Locally

1. Clone the repository:

```bash
git clone https://github.com/amananandsingh01/Portfolio.git
cd Portfolio
```

2. Start a local server:

```bash
python -m http.server 8000
```

3. Open the app in your browser:

```text
http://localhost:8000
```

## Update Content

Edit the project details and profile information in:

- `data.js` — projects, skills, contact details, and metadata
- `main.js` — page rendering logic
- `style.css` — site styling
